# Mobility System

## Model

- `MobilityFlow` captures each flow with:
  - `id`
  - `title`
  - `duration`
  - `type`
  - `goal`
  - `focusAreas`
  - `movements`
  - `instructions`
  - `coachingCues`
  - `whyItMatters`

## Access

- The first two flows remain visible in free preview.
- All Access unlocks the full tennis-specific mobility and recovery library.
- Each flow can link into its own content-anchored discussion thread.

## Launch behavior

- Mobility content is bundled for reliable local access.
- Premium access is enforced by the current subscription entitlement.
- Flow detail screens can refresh their linked discussion thread from the backend when community is available.
