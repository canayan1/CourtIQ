## Common questions

### Subscriptions
- **Manage / cancel:** iOS Settings → Apple ID → Subscriptions, or in-app via Profile → Manage subscription.
- **Refunds:** handled by Apple. Visit https://reportaproblem.apple.com to request one.
- **Restore purchase on a new device:** Profile → Restore purchases.

### Data and account
- **Sign in:** Sign in with Apple. Guest mode is also supported.
- **Delete account:** Profile → Delete account. All server-side data is removed within 30 days; local data is wiped immediately.
- **Reset progress without deleting account:** Profile → Reset local data.

### Bugs and feedback
- **Send feedback:** Profile → Beta feedback → Send feedback. The email arrives with your device + app version pre-filled.
- **Report a community comment:** tap the report icon on any comment.
